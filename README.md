# ระบบบันทึกการอบรมพัฒนาทักษะดิจิทัล

Web app บน Google Apps Script ใช้ Google Sheets เป็นฐานข้อมูล และเก็บไฟล์ใบประกาศนียบัตรใน Google Drive

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `Code.gs` | ฝั่งเซิร์ฟเวอร์: โครงสร้างตาราง, API บันทึก/แก้ไข/ลบ, ระบบผู้ดูแล |
| `Index.html` | หน้าจอทั้งหมด (บันทึกการอบรม / รายงาน / ผู้ดูแลระบบ) |
| `Seed.gs` | ข้อมูลจากชีตเดิม (25 คน, 61 รายการ) ที่ปรับรูปแบบแล้ว ใช้นำเข้าครั้งแรก |
| `preview.html` | ไฟล์ทดลองใช้งานในเบราว์เซอร์ ไม่ต้อง deploy (ข้อมูลเก็บในเครื่อง) |
| `dev/` | ตัวจำลอง Apps Script และสคริปต์สร้าง `preview.html` **ไม่ต้องอัปโหลด** |

## ติดตั้งที่บัญชี meetspace.dft@gmail.com (ประมาณ 10 นาที)

> ทุกขั้นตอนต้องทำ**ขณะล็อกอินด้วย meetspace.dft@gmail.com** (แนะนำให้เปิดหน้าต่างไม่ระบุตัวตน หรือแยกโปรไฟล์ Chrome จะได้ไม่สลับบัญชีผิด)
> ชีต, Web app และไฟล์ใบประกาศฯ ทั้งหมดจะเป็นของบัญชีนี้

**A. สร้างชีตและวางโค้ด**
1. เปิด <https://sheets.new> แล้วตั้งชื่อไฟล์ เช่น `ระบบบันทึกการอบรม DFT`
2. ไปที่เมนู **ส่วนขยาย → Apps Script**
3. ไฟล์ `Code.gs` ที่มีอยู่: ลบเนื้อหาเดิมทิ้ง แล้ววางเนื้อหาจาก `Code.gs`
4. กด **+ → สคริปต์** ตั้งชื่อ `Seed` แล้ววางเนื้อหาจาก `Seed.gs`
5. กด **+ → HTML** ตั้งชื่อ `Index` (ต้องสะกดตรงนี้) แล้ววางเนื้อหาจาก `Index.html`
6. กด 💾 บันทึก แล้ว**ปิดแท็บ Apps Script** กลับไปที่ชีต และกดรีเฟรช 1 ครั้ง

**B. ติดตั้งจากเมนูในชีต**

7. จะมีเมนูใหม่ชื่อ **ระบบบันทึกการอบรม** ให้กด **1) ติดตั้ง / ตรวจสอบโครงสร้างชีต**
   - ครั้งแรก Google จะขออนุญาต: ให้กด *ดำเนินการต่อ → เลือกบัญชี meetspace.dft → ขั้นสูง → ไปที่ … (ไม่ปลอดภัย) → อนุญาต*
     (ที่ขึ้นว่าไม่ปลอดภัย เป็นเพราะสคริปต์ยังไม่ผ่านการตรวจของ Google ซึ่งเป็นปกติของสคริปต์ที่เขียนใช้เอง)
   - หลังอนุญาตแล้ว ให้กดเมนู **1)** อีกครั้ง
8. กด **2) นำเข้าข้อมูลจากชีตเดิม** เพื่อนำเข้า 25 คน / 61 รายการ

**C. เปิดใช้งานเป็นเว็บ**

9. กลับไปที่ Apps Script แล้วกด **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่**
   - ประเภท: **เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน (meetspace.dft@gmail.com)**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคนที่มีบัญชี Google** (บัญชี Gmail ธรรมดาเลือก "ภายในกรมฯ" ไม่ได้)
10. คัดลอก URL ที่ได้ (ลงท้ายด้วย `/exec`) ไปใส่ใน `<iframe src="...">` ของหน้า GitHub Pages
11. เปิด Web app → **ผู้ดูแลระบบ** → ใช้รหัสเริ่มต้น `admin1234` → **ตั้งค่าระบบ → เปลี่ยนรหัสผ่านทันที**
12. แชร์ชีตเป็น "ผู้แก้ไข" ให้ผู้ดูแลอีก 1–2 คน เผื่อกรณีเจ้าของบัญชีไม่อยู่

**แก้โค้ดภายหลัง:** หลังวางโค้ดใหม่ ให้ไปที่ **Deploy → จัดการการทำให้ใช้งานได้ → ✏️ แก้ไข → เวอร์ชัน: เวอร์ชันใหม่** URL จะยังเป็นอันเดิม

## สิ่งที่อยู่ในชีตหลังติดตั้ง

| แท็บ | ใช้ทำอะไร |
|---|---|
| `รายงานการอบรม` | **แท็บสำหรับเปิดอ่าน**: แสดงเป็นชื่อจริง 1 แถวต่อ 1 การอบรม ระบบเขียนใหม่ทุกครั้งที่มีการบันทึก จะกรอง เรียง หรือดาวน์โหลดก็ได้ |
| `บุคลากร`, `บันทึกการอบรม` | ข้อมูลจริงของระบบ (เก็บเป็นรหัส) |
| `M_…` | ข้อมูลหลัก เช่น หลักสูตร, หน่วยงานผู้จัด, ตำแหน่ง ฯลฯ |

- แท็บของระบบตั้งค่า**คำเตือนก่อนแก้ไข**ไว้แล้ว ถ้าจะเปลี่ยนข้อมูลให้แก้ผ่านเมนูผู้ดูแลระบบในเว็บ
- ไฟล์ใบประกาศฯ เก็บใน Google Drive: `ใบประกาศนียบัตรการอบรม / ปีงบประมาณ 2569 / ชื่อ_หลักสูตร_วันที่.pdf`

## โครงสร้างข้อมูล (ชีต)

- `บุคลากร`: คำนำหน้า, ชื่อ, ตำแหน่ง, สังกัด, ประเภท, สถานะ
- `บันทึกการอบรม`: บุคลากร, หลักสูตร, หน่วยงานผู้จัด, รูปแบบ, วันที่เริ่ม–สิ้นสุด, ชั่วโมง, ลิงก์ใบประกาศฯ
- ข้อมูลหลัก `M_…`: หลักสูตร, หน่วยงานผู้จัด, ตำแหน่ง, สังกัด, ประเภทเจ้าหน้าที่, คำนำหน้า, รูปแบบการอบรม

ทุกตารางอ้างอิงกันด้วย `id` เมื่อแก้ชื่อหลักสูตรหรือตำแหน่งเพียงที่เดียว ทุกรายงานจะเปลี่ยนตาม
**ไม่ควรแก้ไขหรือลบแถวในชีตโดยตรง** ให้แก้ผ่านเมนูผู้ดูแลระบบ ส่วนการเปิดอ่านให้ใช้แท็บ `รายงานการอบรม`

## สิทธิ์การใช้งาน

- **ทุกคน**: บันทึกการอบรมของตนเอง (เลือกได้หลายหลักสูตรต่อครั้ง) และดูรายงาน
- **ผู้ดูแลระบบ** (ใช้รหัสผ่าน): เพิ่ม แก้ไข ลบ ข้อมูลหลักและรายการอบรมทั้งหมด
  - **เพิ่มหลายรายการ**: คัดลอกคอลัมน์จาก Excel มาวางได้เลย
  - **รวมรายการ**: รวมหลักสูตรหรือชื่อที่ซ้ำกัน โดยย้ายประวัติทั้งหมดไปยังรายการที่ถูกต้อง
  - **ปิดใช้งาน**: ซ่อนจากตัวเลือก แต่ประวัติเดิมยังอยู่ (ใช้แทนการลบเมื่อข้อมูลถูกอ้างอิงอยู่)
  - **ตรวจคุณภาพข้อมูล**: แสดงหลักสูตรที่ผู้ใช้เพิ่มเองซึ่งยังรอตรวจ, รายการที่ไม่ระบุวันที่ และรายการที่ไม่ระบุหน่วยงานผู้จัด

## ทดลองโดยไม่ต้อง deploy

เปิด `preview.html` ในเบราว์เซอร์ ระบบจะนำข้อมูลเดิมเข้าให้อัตโนมัติ (รหัสผู้ดูแล `admin1234`)
ถ้าต้องการล้างข้อมูลทดลอง ให้เปิด `preview.html?reset`
หลังแก้ `Index.html` หรือ `Code.gs` ให้รัน `python3 dev/build_preview.py` เพื่อสร้าง preview ใหม่
